# Historique

## Pack v1.1

Première distribution publique du Mode Manuel. Le guide et le script Windows indiquent où récupérer et comment installer séparément **Buff Card Removal** de ChaoticBrave. Le BPS v1.0 reproduit l'exécutable validé en jeu. [Dépendance requise](DEPENDANCE_CHAOTICBRAVE.md)

## Patch exact v1.0

Patch BPS de 973 octets créé à partir de l'exécutable de référence du Mode Manuel. Le script vérifie les empreintes SHA-256 de la source, du patch et du résultat. [Manifeste](MANIFEST.json)
